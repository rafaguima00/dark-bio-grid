# Dark Bio Grid

Criar uma aplicação web do tipo "link na bio" com um design modular.

Utilizar uma grade (grid) para organizar blocos de diferentes tamanhos.

Adotar um design dark mode imersivo.

Empregar tecnologias específicas, como shadcn/ui e Tailwind CSS.

Seguir uma abordagem mobile-first (priorizando dispositivos móveis).

Definir detalhes visuais, como cores de fundo, estilo dos blocos, acentuação e tipografia.
